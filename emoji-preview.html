Pin emoji, set by set

Five pins the map actually uses — skate, trivia, drawing, happy hour, open mic — drawn by each candidate set inside the real pin bubble, on the day map and the night map. Apple's row is what the app shows today and renders only on Apple devices; the others ship as image assets.

Set🛼 skate🧠 trivia🎨 drawing🍻 happy hour🎤 open mic

Picking a set means bundling ~130 glyphs as assets and rendering an image in the pin instead of text — about a day's work with a script that pulls just the glyphs the keyword table uses. Fluent 3D is my recommendation: it reads at pin size, has the most character, and is MIT-licensed.
